# Multiple endpoints in clinical trials: when one is not enough

Statistical considerations on multiplicity.

- Open the link above in Chrome, Firefox or Edge (or download `index.html` and open it locally; it works offline).

## Contents

The talk follows four points: which multiple endpoints create a multiplicity problem; how the family-wise error rate grows; what ICH, EMA and FDA require (sharing α, ordering α, graphical procedures, with ODYSSEY OUTCOMES as a worked example); and why the key question is not "is it significant?" but "was it in the plan?".
